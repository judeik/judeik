# Jude Ojobor

I’m a full-stack software engineer working across frontend applications, backend APIs and database systems. I started with PHP and MySQL and now build with JavaScript, TypeScript, React and Node.js. My projects include education software, SaaS prototypes and AI-assisted tools that help people make decisions they can review.

## Selected projects

### SmartEd Africa — Codefest Hack 2025, Nigeria

I led the team building a mobile-first education prototype for learners with limited connectivity, including students in displacement camps. The React, TypeScript and Vite prototype explores localized learning, exam preparation and teacher microlearning. The project documentation describes mock sign-in for the demonstration.

- [SmartEd Africa source](https://github.com/judeik/smarted-africa-app) · [Codefest contest listing](https://www.winfest.africa/contests/codefest-nigeria-hackthon)
- [SmartEd team presentation](https://www.youtube.com/watch?v=l7pJ0N_z0Ok) · [Hosted SmartEd prototype](https://smarted-africa-app.vercel.app/)

### CinePilot AI — Agentic Cinema: The Blockbuster Hackathon, 2026

I designed and built a prototype that helps film production teams respond to disruptions. A Node.js backend retrieves production history from ClickHouse through the Model Context Protocol (MCP), ranks recovery options with explicit rules, and uses Gemini to explain trade-offs. The producer reviews the recommendation in a JavaScript interface before the workflow applies the decision.

[CinePilot source and tests](https://github.com/judeik/cinepilot-ai) · [Devpost submission](https://devpost.com/software/cinepilot-ai-wkc37v) · [Hosted demonstration](https://cinepilotapp.vercel.app/)

### SDG4 eLearning — 2025 frontend prototype

This public project explores how students, instructors and administrators might use an online learning platform. The React and Bootstrap prototype documents separate dashboard layouts and navigation for each role, with example course and checkout screens.

[Source and frontend documentation](https://github.com/judeik/sdg4-elearning)

## Mission

I build software that makes learning easier to access and everyday work easier to manage. I start with the people doing the work, then use clear interfaces, sensible data models and tests to make important workflows easier to use and verify.

## Vision

I want to build products that schools and communities can use even when connectivity is limited. I’m developing my skills in healthcare software and African-language AI, with an interest in practical care workflows and tools that help people learn and find information in languages they use every day.
